# Predictive Maintenance Using Multiple Linear Regression

## Project Description
This project uses Multiple Linear Regression to predict machine torque based on operating conditions.

## Dataset
Predictive Maintenance Dataset containing 10,000 records.

## Input Features
- Air Temperature
- Process Temperature
- Rotational Speed
- Tool Wear
- Machine Type

## Target Variable
- Torque (Nm)

## Algorithm
Multiple Linear Regression

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Methodology
1. Dataset Loading
2. Data Exploration
3. Data Preprocessing
4. Categorical Encoding
5. Train-Test Split (80:20)
6. Model Training
7. Torque Prediction
8. Model Evaluation

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## Model Results
- R² Score: 0.7566
- R² Percentage: 75.66%

## Platform
Google Colab and GitHub
